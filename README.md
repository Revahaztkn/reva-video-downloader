# Reva Video Downloader

Windows için Brave, Chrome ve Edge eklentisi. YouTube, X, Instagram ve TikTok videolarını 480p veya 720p seçeneğiyle MP4 olarak kaydeder.

## Kurulum

1. Bu deponun ZIP dosyasını indirip çıkar.
2. Windows'ta **Kur.cmd** dosyasını çalıştır. Yerel yardımcı, yt-dlp, FFmpeg ve Deno'yu indirip doğrular.
3. Brave'de `brave://extensions`, Chrome'da `chrome://extensions` veya Edge'de `edge://extensions` sayfasını aç.
4. **Geliştirici modu**nu aç ve **Paketlenmemiş öğe yükle** ile **eklenti** klasörünü seç.
5. Video sekmesini yenile. Videodaki yeşil düğmeden veya eklentinin araç çubuğu menüsünden kaliteyi seç.

MP4 dosyası Windows'un **İndirilenler** klasörüne kaydedilir. Kaynak daha düşük çözünürlükteyse görüntü büyütülmez. Herkese açık ve indirme iznin olan videoları kullan.
